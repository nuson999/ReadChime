# Play Books 리더 감지 근거

현재 체크아웃에는 아래에서 언급하는 원본 HTML 두 개가 없습니다. 아래 저장본 관측은 앞선 작업의 근거 기록으로 보존합니다. 현재 자동 검사는 `tests/fixtures.ts`의 합성 DOM으로 실행하며, 원본 HTML이나 실제 로그인한 Google 화면을 이번에 검증했다는 뜻은 아닙니다.

## 서재 목록 감지 (0.2.0)

서재 감지는 대시보드의 **Play Books에서 가져오기** 버튼에서만 실행하는 별도 감지기입니다. 독서 타이머의 주기적 관측이나 페이지 방문 시에는 호출하지 않습니다.

제공된 `Google Play 북.htm`의 `gpb-library-home`, `gpb-shelf-page`, 선택된 `a.navbar-item.your-books.selected`, `.-gb-book-card-grid`가 함께 존재하는지 확인합니다. 이 그리드 안의 `div.card.ebook`만 검사하고, `.metadata a.title`, `.metadata a.author`, 검증된 `/books/reader?id=…` 링크에서 제목·저자·주소를 읽습니다. 공개 스토어의 카드나 그리드 밖 선반·추천 링크는 대상이 아닙니다.

원본에는 카드 100개, 고유 리더 ID 100개, 반복된 리더 링크 300개가 있습니다. 저자는 99권에서 비어 있지 않습니다. 카드 안의 반복 링크를 책으로 추가 집계하지 않고, 같은 책 ID의 반복 카드도 제거합니다. 제목이나 리더 ID가 불명확한 카드는 제외하고 개수를 표시합니다.

원본에 ‘다음 100개’와 ‘모두 표시’ 컨트롤이 있어 100권을 전체 서재라고 판단하지 않습니다. 감지기는 DOM을 읽기만 하며 페이지 버튼을 누르거나 숨은 계정 API로 나머지 목록을 요청하지 않습니다. 최대 2,000개 카드까지만 읽고 초과 시 부분 결과임을 표시합니다. 빈 목록·로딩·로그인 필요·미지원 구조도 서로 구분합니다.

실제 Firefox에서는 Google `/books` 탭의 본문을 **합성 서재 메타데이터**로 교체해 콘텐츠 스크립트 → 백그라운드 → 미리보기 → 선택 저장의 전체 연결을 검증합니다. 이것을 로그인한 실제 Google 서재의 현행 DOM 검증으로 해석하지 않습니다. 원본 저장본의 100권 파싱 테스트와 별도입니다.

실사용에서는 Google에서 로그인한 내 서재를 연 다음 대시보드에서 감지하고, 최초에는 소수의 책을 선택해 제목·저자·연결 주소를 확인하세요. 전체가 필요하면 Google에서 ‘모두 표시’를 직접 누르거나 다음 페이지를 준비한 뒤 다시 실행합니다.

## 현재 근거

사용자가 제공한 로컬 저장본을 직접 확인했습니다.

| 자료 | 확인한 구조 |
|---|---|
| `Accelerando - Google Play 북 reading page.htm` | `reader-control` 1개, `iframe.-gb-display` 1개 |
| `Google Play 북.htm` | 위 리더 구조 없음. `https://play.google.com/books/reader?id=…` 형태 링크 있음 |

콘텐츠 스크립트는 HTTPS의 정확한 `play.google.com` 호스트, `/books/reader` 경로와 안전한 책 ID, 두 바깥 DOM 구조를 함께 확인합니다. URL만으로 읽는다고 판단하지 않습니다. 페이지 내부 iframe이나 책 본문은 읽지 않습니다. 저장된 iframe 파일 자체를 분석할 필요도 없습니다.

`ReaderDetector` 인터페이스와 `playBooksDetector` 구현을 분리해 사이트가 바뀌면 감지기만 교체할 수 있습니다. 감지 실패는 한국어 안내와 사용자 확인 타이머로 처리합니다. 감지 성공도 주의 집중·독서 이해·책 접근 권한의 증거는 아닙니다.

## 검증 경계

Vitest는 원래 HTML 저장본의 구조를 이용해 홈과 리더 후보를 구분합니다. 브라우저 이벤트 배선은 별도의 모의 API 통합 테스트로 확인합니다. 실제 Firefox에서는 확장 설치·UI·수동 기록·저장·백업을 확인했습니다.

**실제 로그인한 Play Books의 현행 리더에서 자동 감지를 검증한 것은 아닙니다.** 다른 책 형식·Google UI 실험·계정 언어·화면 개편에서 구조가 다를 수 있습니다. 자동 시작은 기본 꺼짐입니다.

## 실제 책에서 확인할 순서

1. 확장을 설치하고 Play Books 접근 권한을 허용합니다.
2. 실제 책을 열고 주소를 서재에 등록합니다.
3. 처음에는 자동 시작을 끈 채 **독서 시작**으로 연결합니다.
4. 감지 실패 안내가 있으면 리더임을 직접 확인한 뒤 체크박스를 사용합니다.
5. 책을 전면에 둔 20초, 다른 탭의 20초, 다른 창·최소화의 20초를 비교합니다. 전면 관측 구간만 저장되어야 합니다.
6. 직접 일시정지 후 탭을 다시 열어도 멈춰 있는지 확인합니다.
7. 절전·브라우저 종료 후 불확실한 공백이 더해지지 않고 직접 재시작해야 하는지 확인합니다.
8. 자동 시작을 켠 뒤 등록된 동일 책에만 연결되고 홈페이지·다른 책에는 연결되지 않는지 확인합니다.

본문·DRM 자료·Google 계정·구매 목록·쿠키를 수집하거나 계정 제한을 우회하는 방식으로 감지 범위를 확장하지 않습니다.
