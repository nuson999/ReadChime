# ReadChime 검증 기록

## Mozilla 서명본의 일반 설치와 재시작 유지 (0.2.1)

2026년 10월 21일, Mozilla 비공개(직접 배포) 버전 0.2.1의 승인과 서명 XPI 다운로드를 확인했습니다. 서명본은 `artifacts/readchime-0.2.1-signed.xpi`입니다. 제출한 런타임 파일은 SHA-256이 동일하고, manifest는 Mozilla가 들여쓰기만 정규화했으며 필드와 값이 같습니다. `META-INF/` 서명 메타데이터 5개가 포함되어 있습니다.

`node scripts/smoke-signed-firefox.mjs`는 별도 Firefox 158.0.1 프로필에서 임시 확장에 합성 책 데이터를 만든 뒤, 기존 확장을 삭제하지 않고 서명본을 일반 설치했습니다. 이후 Firefox를 완전히 종료하고 같은 프로필을 다시 실행하되 재설치 API를 호출하지 않았습니다. 확장이 정상 로드되고 책·설정 데이터가 유지되는 것을 확인했습니다. 프로필 메타데이터는 `app-profile`, `signedState: 2`입니다.

이는 사용자 기본 Firefox 프로필에 설치했다는 뜻은 아닙니다. 사용자는 Firefox 부가 기능 관리자의 **파일에서 부가 기능 설치**로 서명 XPI를 한 번 설치하면 됩니다. 검증 기록은 `.tmp/signed-firefox-qa.json`, 화면은 `.tmp/signed-firefox-restart.png`에 있습니다.

## 현재 책 자동 선택과 시작 안내 (0.2.1)

2026년 10월 21일(한국 시간), 격리된 Firefox 158.0.1 프로필에서 검증했습니다. 등록 리더 URL의 책 ID 대조와 기존 제목·저자 유지, 클릭 전 무기록, 실제 시작 버튼 클릭 뒤 타이머 연결, 다른 탭의 시간 제외, 책 전환 시 이전 구간 저장과 새 시작 입력 대기, 종료 뒤 안내 반복 방지를 확인했습니다. 도구 모음 팝업 API가 거절되는 환경은 테스트에서 재현해 페이지 내 안내의 실제 클릭을 검사했고, 마지막에는 실제 도구 모음 팝업 자동 열기와 그 문서에 표시된 현재 책·시작 버튼도 확인했습니다.

Firefox에서 같은 문서의 `history.replaceState`로 읽기 주소를 바꾸면 메시지의 `sender.url`은 처음 서재 주소로 남고 `sender.tab.url`은 새 리더 주소가 되는 것을 관측했습니다. 현재 탭 URL을 다시 확인하는 처리와 회귀 테스트를 추가했습니다. 이벤트 페이지 재생성·페이지 위치 변경·일반 새로고침에서도 안내 표시 여부가 유지되고, 책 변경·탭 닫힘에서는 초기화하는 세션 저장 동작도 검사합니다.

`npm run test:firefox:reader`, `npm run test:firefox:library`, `npm run test:firefox:i18n`을 통과했습니다. 합성 서재 100권의 선택 가져오기와 한국어·영어 설정·백업·재시작 검증도 유지됩니다. 리더 테스트는 허용된 Google origin에서 **합성 리더 바깥 구조·제목**을 사용했으며 로그인한 실제 계정의 책 DOM이나 본문을 검증한 것은 아닙니다. 사용자 상시 설치 확장을 이 테스트로 업데이트하지 않았습니다.

`npm run check`도 통과했습니다. 타입·ESLint·73개 테스트·배포 빌드·자산 경로 검사를 완료했고, Firefox 확장 검사는 오류 0·알림 0·기존 React DOM 경고 2개입니다.

검증 산출물: `.tmp/reader-firefox-qa.json`, `.tmp/reader-prompt.png`. 재실행 명령은 `npm run test:firefox:reader`입니다. 아래는 이전 변경 당시의 기록으로 보존합니다.

## 실제 Firefox

`npm run test:firefox`로 Firefox **158.0.1**, GeckoDriver **0.37.1**, 헤드리스 모드에서 확인했습니다.

- 배포 폴더를 임시 확장으로 설치하고 React 대시보드를 로드했습니다.
- 첫 실행은 책·기록 0개입니다. 테스트 데이터가 사용자 프로필에 삽입되지 않습니다.
- 실제 서재 폼으로 책을 추가했습니다. HTML 모양의 메모가 실행되지 않고 텍스트로 표시됨을 확인했습니다.
- 실제 수동 기록 폼으로 태블릿 독서 5분을 저장했습니다.
- 저장값을 기반으로 차트와 목표 달성 달력이 렌더링됨을 확인했습니다.
- 실제 `browser.storage.local`에서 JSON 내보내기·동일 ID 병합·충돌 보존을 확인했습니다.
- 명시적으로 확인한 백업 전체 교체도 실행하고 완료 기록이 유지됨을 확인했습니다.
- `browser.alarms`에 설정한 현지 시각의 일회성 알림이 예약됨을 확인했습니다.
- 다음 분의 실제 알람 발화까지 기다려 책 주소가 없는 경우 책 선택 화면이 열리고 당일 처리 상태가 한 번만 기록됨을 확인했습니다.
- 밝은 화면·다크 모드·좁은 화면·팝업 페이지를 확인하고 스크린샷을 검토했습니다.
- 책을 서재에서 제거해도 완료 기록이 유지됨을 확인했습니다.
- Firefox를 종료하고 같은 테스트 프로필에 동일 ID의 임시 확장을 다시 설치했을 때 기록이 남아 있음을 확인했습니다. 이는 서명본의 상시 설치 또는 일반 제거 동작 검증이 아닙니다.

기계 판독 결과는 `.tmp/firefox-qa.json`, 로그는 `.tmp/geckodriver.log`, 화면은 `.tmp/*-dark.png`, `.tmp/stats-light.png`, `.tmp/home-narrow.png`에 있습니다. 재실행하면 해당 출력은 갱신됩니다. 테스트 프로필과 자료는 배포 패키지에 포함하지 않습니다.

## 보이는 책 측정·5초 유예·페이지 재개 (2026-10-22)

`npm run check`의 타입 검사·ESLint·자동 테스트 81개·배포 빌드가 통과했습니다. Firefox 확장 검사는 오류 0개이며, React vendor 번들의 `innerHTML` 경고 2개가 남습니다.

- 보이는 책은 창 포커스가 없어도 측정하며, 최소화·숨김 시간은 제외합니다.
- 숨김 후 정확히 5초까지는 버튼 없이 복귀하고, 5초를 넘기면 명시적 재개가 필요합니다. 반복 숨김 관측이 유예를 연장하지 않습니다.
- 지연된 콜백과 이벤트 페이지 재로드에도 저장된 유예 시작 시각을 확인합니다.
- 같은 책 새로고침·서재 왕복·중복 탭 선택은 같은 세션을 유지합니다. 다른 창의 보이는 책은 세션을 가져가거나 종료하지 않습니다.
- 페이지 재개는 현재 세션 ID·책 ID·탭과 표시 상태를 검사하며 오래된 버튼의 요청을 거부합니다.

`npm run test:firefox:reader`는 격리된 **Firefox 158.0.1**에서 합성 리더를 사용해 다음을 확인했습니다.

- 5초 초과 숨김 후 일시정지, 숨김 시간 미합산, 5초 이내 탭 왕복 후 버튼 없는 복귀
