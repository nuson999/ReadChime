# ReadChime 검증 기록

## 한국어·영어 지원 추가 검증 / Localization verification

2026년 10월 21일(한국 시간), 별도 임시 Firefox 프로필에서 확인했습니다. 아래는 이번 언어 지원 변경에 대한 결과이며, 뒤의 기존 검증 기록과 구분합니다.

| 검사 / Check | 결과 / Result |
|---|---|
| `npm run check` | 통과: 타입·린트·62개 테스트·빌드·배포 자산 확인 |
| `web-ext lint` | 오류 0, 알림 0, 기존 React DOM 경고 2 |
| `npm run test:firefox:i18n` | Firefox 158.0.1에서 통과 |
| `npm run test:firefox` | 설치·서재·수동 기록·통계·백업·알람·재시작 회귀 검사 통과 |
| `npm run test:firefox:library` | 합성 서재의 탭 선택·선택 가져오기 회귀 검사 통과 |

언어 검사에서는 Firefox 표시 언어가 `en-US`인 환경의 시스템 기본값과 영어 manifest 메타데이터, 다섯 대시보드 화면과 책·독서 기록 편집 창, 팝업, 접근성 이름, 문서의 `lang`·제목, 설정을 저장했을 때 이미 열린 화면 간 반영, 재시작 후 유지, JSON 백업과 이전 백업 병합, 백그라운드 오류의 영어 표시를 확인했습니다. 한국어로 전환한 대시보드와 팝업도 확인했고, 두 언어의 설정 화면 스크린샷을 검토했습니다. 사용자 책 제목·저자·메모·독서 기록은 보존했습니다.

단위·통합 테스트는 한국어 시스템 언어 판정, 명시적 언어 우선, 영어 폴백, 모든 원문 문구의 번역 유무와 변수 자리 보존, 저장된 오류와 스키마 오류 표시, 언어가 없는 버전 2 데이터·백업의 기본값, 백업 설정 선택 여부, 두 언어 알림 내용을 검증합니다. 알림 내용 검사는 모의 Firefox API를 사용하며 실제 OS 알림 클릭을 검증한 것은 아닙니다. 한국어 Firefox 언어 팩을 설치한 환경의 부가 기능 목록은 이번에 실행하지 않았고, 두 언어의 메타데이터 파일·변수는 빌드 검사로 확인했습니다.

Current localization checks passed in isolated Firefox 158.0.1, including dashboard/popup updates, restart persistence, legacy backup handling, and preservation of user content. The test browser UI was English. Korean app screens were checked by selecting Korean inside ReadChime. Notification text was checked with mocked APIs; authenticated Play Books and real OS notification clicks remain unverified.

재현 산출물은 `.tmp/i18n-firefox-qa.json`, `.tmp/i18n-en-settings.png`, `.tmp/i18n-ko-settings.png`에 생성됩니다. `.tmp/`는 Git에 포함하지 않습니다. 제한된 샌드박스에서는 GeckoDriver 로컬 서버 시작이 시간 초과되어, 같은 격리 프로필 테스트를 샌드박스 밖에서 실행해 통과했습니다.

원본 Play Books HTML은 현재 체크아웃에 없어, 해당 파일을 직접 읽던 두 테스트를 `tests/fixtures.ts`의 합성 DOM으로 바꿨습니다. 저장본 관측과 현재 실행한 합성 DOM 검증을 혼동하지 않습니다.

테스트 범위는 현지 시각 예약·DST·놓친 알림·당일 중복·다시 알림·자정 만료·목표 달성 억제, URL 검증과 추천, 저장본 기반 리더 구분, 포커스·일시정지·재개·시계 역행·절전 공백·자정 분할·목표 이후 계속 측정, 여러 기록의 합산, 과거 목표 보존, 저장 직렬화·실패 보존·이전·백업 검증·ID 병합·충돌 선택입니다.

백그라운드 통합 테스트는 실제 백그라운드 모듈에 모의 Firefox API를 연결합니다. 대시보드 탭 발신 허용과 외부 발신 거부, 이중 타이머 방지, 시작 이벤트 복구, 서재 삭제·영구 삭제 확인, 가져오기 확인·변경 충돌도 검증합니다. 이 테스트를 실제 책 페이지에서 읽은 결과로 해석하지 않습니다.

`web-ext` 경고 2개는 `assets/react-vendor-*.js`의 React DOM 내부 `innerHTML` 대입입니다. 앱은 사용자 HTML 삽입 API를 호출하지 않으며, 경고를 숨기지 않습니다. 빌드에서 Zod 배포 주석의 순수성 표기 위치 경고도 발생하나 빌드는 성공합니다. 환경에 따라 `web-ext`의 자체 업데이트 확인 실패 안내가 추가로 표시될 수 있으며 확장 검사 결과와는 별개입니다.

## 서재 가져오기 추가 검증 (0.2.0)

서재 기능 관련 검사도 위 55개에 포함합니다. 원래 서재 HTML의 카드 100개와 고유 ID 100개, 저자가 있는 99권을 실제 DOM 파서로 확인했습니다. 공개 추천 제외, 로그인·로딩·미지원·빈 목록 구분, 잘못된 주소·카드·반복 ID, 2,000개 제한, 수동 메타데이터 보존, 명시 복원, 기존 중복 차단, 미리보기 이후 변경·만료·재반영도 검증합니다.

콘텐츠 스크립트를 실제로 초기화하고 주기 관측과 포커스 이벤트를 발생시켜도 서재 감지기가 호출되지 않으며, 명시적인 `SCAN_LIBRARY` 메시지에서만 호출됨을 확인했습니다. 백그라운드는 팝업에서의 서재 감지 요청을 거부하고 브라우저 시작 시에도 목록을 감지하지 않습니다.

`npm run test:firefox:library`는 별도 Firefox 158.0.1에 배포 확장을 설치하고, Google `/books` 탭의 본문을 사용자 계정과 무관한 **합성 서재 DOM**으로 교체해 검사합니다. 실제 Google 계정의 현행 목록을 확인한 결과가 아닙니다.

- 여러 탭 중 대상 선택, 로그인 필요 화면의 별도 안내
- 100권의 콘텐츠 스크립트 감지 → 백그라운드 검증 → 대시보드 선택 미리보기, 반영 전 영구 책 추가 없음
- 신규 97권을 ‘읽을 책’으로 추가, 제거된 책의 명시 복원, 선택한 빈 저자만 보완
- 기존 제목·상태·메모·UUID·세션·현재 책과 주소 없는 수동 책 보존, 기존 중복 UUID는 자동 병합하지 않음
- 다시 감지해도 추가 중복 없음, 페이지 방문·주기 관측에서 자동 수집 없음, Google 페이지 버튼 자동 클릭 없음

결과는 `.tmp/library-firefox-qa.json`, 화면은 `.tmp/library-import-preview.png`에 기록합니다. 원본 저장본 파싱과 합성 DOM을 사용한 실제 브라우저 배선 검증을 구분합니다.

## 실제 Firefox

`npm run test:firefox`로 Firefox **158.0.1**, GeckoDriver **0.37.1**, 헤드리스 모드에서 확인했습니다.

- 배포 폴더를 임시 확장으로 설치하고 React 대시보드를 로드했습니다.
- 첫 실행은 책·기록 0개입니다. 테스트 데이터가 사용자 프로필에 삽입되지 않습니다.
- 실제 서재 폼으로 책을 추가했습니다. HTML 모양의 메모가 실행되지 않고 텍스트로 표시됨을 확인했습니다.
- 실제 수동 기록 폼으로 태블릿 독서 5분을 저장했습니다.
- 저장값을 기반으로 차트와 목표 달성 달력이 렌더링됨을 확인했습니다.
- 실제 `browser.storage.local`에서 JSON 내보내기·동일 ID 병합·충돌 보존을 확인했습니다.
- 명시적으로 확인한 백업 전체 교체도 실행하고 완료 기록이 유지됨을 확인했습니다.
- `browser.alarms`에 설정한 현지 시각의 일회성 알림이 예약됨을 확인했습니다.
- 다음 분의 실제 알람 발화까지 기다려 책 주소가 없는 경우 책 선택 화면이 열리고 당일 처리 상태가 한 번만 기록됨을 확인했습니다.
- 밝은 화면·다크 모드·좁은 화면·팝업 페이지를 확인하고 스크린샷을 검토했습니다.
- 책을 서재에서 제거해도 완료 기록이 유지됨을 확인했습니다.
- Firefox를 종료하고 같은 테스트 프로필에 동일 ID의 임시 확장을 다시 설치했을 때 기록이 남아 있음을 확인했습니다. 이는 서명본의 상시 설치 또는 일반 제거 동작 검증이 아닙니다.

기계 판독 결과는 `.tmp/firefox-qa.json`, 로그는 `.tmp/geckodriver.log`, 화면은 `.tmp/*-dark.png`, `.tmp/stats-light.png`, `.tmp/home-narrow.png`에 있습니다. 재실행하면 해당 출력은 갱신됩니다. 테스트 프로필과 자료는 배포 패키지에 포함하지 않습니다.
