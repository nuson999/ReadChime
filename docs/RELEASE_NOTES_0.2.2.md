# ReadChime 0.2.2

## 한국어

- 책 탭이 선택되어 있고 화면에 보이면 다른 앱에서 메모하는 동안에도 독서 시간을 계속 측정합니다.
- 탭 전환·최소화 후 5초 안에 돌아오면 버튼 없이 이어 갑니다. 숨겨진 시간은 합산하지 않습니다.
- 5초를 넘기거나 직접 일시정지하면 책 페이지 오른쪽 위의 읽기 재개 버튼을 눌러 이어 갑니다. 안내는 작은 버튼으로 접을 수 있습니다.
- 새로고침·서재 왕복·같은 책의 다른 탭 선택에도 기록을 이어 가며, 다른 창의 책이 기록을 임의로 가져가지 않도록 했습니다.
- 추가 권한이나 외부 데이터 전송은 없습니다.

## English

- Keep measuring visible reading while taking notes in another application.
- Return within five seconds after hiding the book to continue automatically; hidden time is excluded.
- Longer absences and manual pauses show a Resume reading card at the top right of the reader. Collapse it to a small resume button if preferred.
- Preserve the session across reloads, library visits, and directly selected tabs of the same book, without allowing readers in other windows to take over.
- No additional permissions or external data transmission.
