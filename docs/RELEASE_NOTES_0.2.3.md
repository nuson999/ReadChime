# ReadChime 0.2.3

## 한국어

- 팝업과 대시보드가 더 빨리 열립니다. 팝업은 차트 라이브러리를 불러오지 않고, 통계 차트는 통계 화면을 열 때만 불러옵니다.
- 5초마다 기록을 다시 읽던 방식을 없애고 저장 내용이 바뀔 때만 화면을 갱신합니다.
- 누른 버튼에만 진행 표시가 나타나고 다른 버튼은 계속 사용할 수 있습니다.
- 독서 달력은 탭 한 번으로 들어가 화살표 키로 날짜를 이동하며, 선택한 날짜의 기록을 아래에 표시합니다.
- 글자 색 대비와 최소 글자 크기를 높이고 아이콘을 선명한 그림으로 바꿨습니다.
- Play Books의 시작 안내가 설정한 밝은/어두운 테마를 따릅니다.
- 팝업을 오늘의 진행 상황과 시작 버튼 중심으로 간결하게 정리했습니다. 직접 기록은 대시보드의 독서 기록에서 할 수 있습니다.
- 추가 권한이나 외부 데이터 전송은 없습니다.

## English

- The popup and dashboard open faster. The popup no longer loads the chart library, and the statistics chart loads only when you open Statistics.
- The 5-second refresh is gone; screens update only when stored data changes.
- Only the button you press shows progress; other buttons stay usable.
- The reading calendar is a single tab stop with arrow-key navigation and shows the selected day's total below it.
- Higher text contrast, a 12px minimum text size, and crisp SVG icons.
- The Play Books start prompt follows your light/dark theme setting.
- The popup focuses on today's progress and the start button. Log reading time manually from Reading history in the dashboard.
- No additional permissions or external data transmission.
