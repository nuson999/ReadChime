# ReadChime 0.2.5

## 한국어

- 독서 시간을 기록하는 동안 도구 모음 아이콘에 빨간색 **REC** 배지가 표시됩니다.
- 독서가 일시정지되었거나 책 화면으로 돌아오기를 기다리는 동안에는 회색 **II** 배지가 표시됩니다.
- 아이콘에 마우스를 올리면 지금 읽고 있는 책 제목이 보입니다.
- 권한과 데이터 처리 방식은 바뀌지 않았습니다.

## English

- The toolbar icon shows a red **REC** badge while reading time is being recorded.
- A grey **II** badge appears while a session is paused or waiting for you to return to the book.
- Hovering the icon shows the book currently being read.
- No changes to permissions or data handling.
