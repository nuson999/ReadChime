# ReadChime 0.2.6

## English

- First public release on Mozilla Add-ons, following self-distributed version 0.2.5.
- Manage a reading library, set daily reminders, and review reading history and statistics.
- Start the Google Play Books reading timer with an explicit click, or enter reading time manually for other devices and paper books.
- English and Korean interfaces, light and dark themes, and local JSON backup and restore.
- Reading data stays in Firefox; no analytics, developer account, or cloud synchronization.
- Runtime behavior and permissions are unchanged from 0.2.5.

## 한국어

- 직접 배포하던 0.2.5에 이어 Mozilla 부가 기능에 처음 공개하는 버전입니다.
- 서재를 관리하고 매일 알림을 받으며 독서 기록과 통계를 확인할 수 있습니다.
- Google Play Books에서는 시작 버튼을 누른 뒤 시간을 기록합니다. 다른 기기나 종이책에서 읽은 시간은 직접 입력할 수 있습니다.
- 한국어·영어, 밝은·어두운 테마, JSON 파일 백업과 복원을 지원합니다.
- 독서 데이터는 Firefox에 저장됩니다. 분석 도구, 개발자 계정 서비스, 클라우드 동기화를 사용하지 않습니다.
- 동작과 권한은 0.2.5와 같습니다.
