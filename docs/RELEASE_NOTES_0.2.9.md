# ReadChime 0.2.9

## English

- Refined the dashboard and popup: tighter, more even spacing, a quieter sidebar, lighter headings, and a neutral dark theme instead of a green-tinted one.
- Library book spines now show each book's title.
- Buttons and links use drawn icons instead of text arrows and plus signs.
- The "Current book" badge in the library no longer pulses; only the running timer's badge does.
- Permissions and data handling are unchanged from 0.2.8.

## 한국어

- 대시보드와 팝업을 다듬었습니다. 간격을 고르게 맞추고, 사이드바를 차분하게 정리하고, 제목 굵기를 낮추고, 다크 테마를 초록빛 대신 중립적인 색으로 바꿨습니다.
- 내 서재의 책등에 책 제목이 표시됩니다.
- 버튼과 링크의 화살표·더하기 기호를 아이콘으로 바꿨습니다.
- 내 서재의 "현재 책" 표시는 더 이상 깜박이지 않습니다. 실제로 측정 중인 타이머만 깜박입니다.
- 권한과 데이터 처리 방식은 0.2.8과 같습니다.
